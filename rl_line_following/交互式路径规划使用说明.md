# 交互式路径规划使用说明

## 🎯 功能说明

现在您可以在Rviz中**直接点击**来创建路径，不再需要修改代码！

## 🚀 使用方法

### 步骤1：启动系统

```bash
source ~/catkin_ws/devel/setup.zsh
cd ~/catkin_ws/src/rl_line_following
roslaunch rl_line_following complete_system.launch
```

### 步骤2：在Rviz中添加路径显示

1. 在Rviz左侧面板点击 **"Add"** 按钮
2. 选择 **"By topic"** 选项卡
3. 找到并添加以下显示：
   - **Marker** (订阅 `/planner/markers`) - 显示路径点（红色小球）
   - **Path** (订阅 `/planner/path`) - 显示路径连线（绿色线条）

### 步骤3：开始绘制路径

1. 在Rviz工具栏上方找到 **"2D Nav Goal"** 工具（通常是一个绿色箭头图标）
2. 点击 **"2D Nav Goal"** 工具使其激活（图标会高亮）
3. 在Rviz的3D视图中，点击地图上的任意位置
4. 拖动鼠标来设置目标点的朝向（可选）
5. 释放鼠标，路径点已添加！

### 步骤4：继续添加更多路径点

- 重复步骤3，可以连续添加多个路径点
- 每个点击的点都会被添加到路径中
- 路径会按照添加的顺序连接

### 步骤5：小车自动跟踪

- 一旦添加了路径点，`path_tracker` 节点会自动让小车沿着路径行驶
- 小车会依次访问每个路径点

## 🗑️ 清空路径

如果需要重新规划路径，可以清空当前路径：

**方法1：使用服务**
```bash
source ~/catkin_ws/devel/setup.zsh
rosservice call /planner/clear_path
```

**方法2：使用快捷脚本**
```bash
./clear_path.sh
```

## 📋 完整操作流程示例

```bash
# 1. 启动系统
source ~/catkin_ws/devel/setup.zsh
roslaunch rl_line_following complete_system.launch

# 2. 在Rviz中：
#    - 添加 Marker 显示（/planner/markers）
#    - 添加 Path 显示（/planner/path）

#    - 在地图上点击多个点创建路径

rosservice call /planner/clear_path
# 或
./clear_path.sh
```

## 🎨 Rviz显示配置

### 推荐的Rviz显示设置

1. **Grid** - 网格（固定坐标系）
2. **RobotModel** - 机器人模型
3. **Marker** - 路径点标记（订阅 `/planner/markers`）
4. **Path** - 路径连线（订阅 `/planner/path`）
5. **Camera** - 摄像头视图（可选，订阅 `/depth_camera/rgb/image_raw`）

### 确保Fixed Frame设置正确

- 在Rviz左侧底部找到 "Global Options"
- 确保 "Fixed Frame" 设置为 **"map"**

## 🔧 故障排除

### 问题1：点击2D Nav Goal后没有反应

**检查：**
```bash
source ~/catkin_ws/devel/setup.zsh
rostopic echo /move_base_simple/goal
```
然后再次点击，看是否有消息发布。

**解决方案：**
- 确保 `rviz_path_planner` 节点正在运行
- 检查终端中是否有 "添加路径点" 的日志输出

### 问题2：看不到路径点和连线

**解决方案：**
1. 在Rviz中添加 Marker 和 Path 显示类型
2. 确保订阅的话题名称正确：
   - Marker: `/planner/markers`
   - Path: `/planner/path`
3. 检查Fixed Frame是否为 "map"

### 问题3：小车不移动

**检查路径是否发布：**
```bash
source ~/catkin_ws/devel/setup.zsh
rostopic echo /planner/path
```

**检查控制命令：**
```bash
rostopic echo /cmd_vel
```

**解决方案：**
- 确保至少添加了1个路径点
- 确保 `path_tracker` 节点正在运行
- 检查odom话题是否正常：`rostopic echo /odom`

## 💡 提示

1. **路径点的顺序很重要** - 小车会按照您点击的顺序依次访问路径点
2. **可以随时清空重新规划** - 使用清空服务后，可以重新点击创建新路径
3. **路径点会自动连接** - 相邻的路径点会自动用绿色线条连接
4. **朝向信息** - 拖动鼠标时可以设置目标点的朝向，但这不影响路径跟踪（只影响2D Nav Goal的显示）

## 📊 可视化效果

- 🔴 **红色小球** = 路径点（Marker）
- 🟢 **绿色线条** = 路径连线（Path）
- 🤖 **机器人模型** = 当前小车位置
- 📷 **摄像头窗口** = OpenCV显示的实时图像
