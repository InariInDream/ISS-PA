# Rviz路径跟踪和摄像头查看功能 - 使用说明

## ✅ 已修复和更新的功能

### 1. 摄像头图像查看 ✅
- ✅ 已更新话题名称为：`/depth_camera/rgb/image_raw` 和 `/depth_camera/depth/image_raw`
- ✅ 修复了zsh兼容性问题（脚本shebang改为`#!/usr/bin/env zsh`）
- ✅ camera_viewer.py 现在会在OpenCV窗口中显示实时摄像头画面

### 2. Rviz路径跟踪 ✅
- ✅ 小车可以按照预定义的路径自动行驶
- ✅ 在Rviz中可以可视化路径和机器人

## 🚀 快速开始

### 步骤1：编译工作空间（如果还没编译）

```bash
cd ~/catkin_ws
catkin_make
source devel/setup.bash
```

### 步骤2：启动完整系统

**方式1：一键启动所有功能（推荐）**

```bash
cd ~/catkin_ws/src/rl_line_following
roslaunch rl_line_following complete_system.launch
```

这会启动：
- ✅ Gazebo仿真环境
- ✅ Rviz可视化界面
- ✅ **OpenCV窗口显示摄像头**（RGB和深度）
- ✅ 路径规划器
- ✅ 路径跟踪器（小车自动行驶）

**方式2：分别启动（如果需要调试）**

终端1 - 启动Gazebo：
```bash
roslaunch rl_line_following rviz_path_following.launch
```

终端2 - 启动摄像头查看器（如果需要单独查看）：
```bash
rosrun rl_line_following camera_viewer.py
```

### 步骤3：在OpenCV窗口中查看摄像头

启动后会自动打开两个窗口：
- 🖼️ **RGB Camera View** - 显示机器人前向摄像头的彩色图像
- 🖼️ **Depth Camera View** - 显示深度信息（彩色编码）

### 步骤4：在Rviz中查看路径

Rviz会自动打开，你可以：
1. 在3D视图中看到机器人模型
2. 看到预定义的路径（绿色线条）
3. 看到小车沿着路径自动行驶

## 🖱️ 交互式路径规划（新功能！）

**不再需要hardcode路径了！** 现在您可以在Rviz中直接点击来创建路径：

1. 在Rviz工具栏点击 **"2D Nav Goal"** 工具
2. 在地图上点击任意位置添加路径点
3. 可以连续点击多个点来创建完整路径
4. 小车会自动按照您点击的路径行驶

详细说明请查看：`交互式路径规划使用说明.md`

## 🗑️ 清空路径

如果需要重新规划路径，可以清空当前路径：

```bash
source ~/catkin_ws/devel/setup.zsh
rosservice call /planner/clear_path
```

或使用快捷脚本：
```bash
./clear_path.sh
```

## 🎥 摄像头话题说明

根据您的检查，摄像头发布的话题是：

- `/depth_camera/depth/image_raw` - 深度图像

## 🐛 故障排除

### 问题1：摄像头窗口没有打开

**解决方案**：
1. 检查摄像头话题是否存在：
   ```bash
   rostopic list | grep camera
   ```

2. 检查cv_bridge是否正确安装：
   ```bash
   python3 -c "import cv_bridge; print('OK')"
   ```

3. 如果没有安装，运行：
   ```bash
   sudo apt-get install ros-noetic-cv-bridge
   ```

### 问题2：小车不移动

**解决方案**：
1. 检查路径是否发布：
   ```bash
   rostopic echo /planner/path
   ```

2. 检查odom话题：
   ```bash
   rostopic echo /odom
   ```

### 问题3：Rviz显示警告

**解决方案**：
确保Fixed Frame设置为 `map`：
- 在Rviz左下方找到 "Global Options"
- 设置 "Fixed Frame" 为 "map"
