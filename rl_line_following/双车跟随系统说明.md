# 双车跟随系统说明

## ✅ 已实现的功能

1. **第二辆小车** - 在第一辆车正后方1米处spawn
2. **跟随控制器** - 第二辆车自动跟随第一辆车的轨迹

## 🚀 启动系统

```bash
source ~/catkin_ws/devel/setup.zsh
roslaunch rl_line_following complete_system.launch
```

## 🔧 配置说明

### 第二辆车位置

- **第一辆车**: x=2.0, y=-0.7, Y=3.14 (180度，向后)
- **第二辆车**: x=1.0, y=-0.7 (正后方1米), Y=3.14 (相同朝向)

### 跟随参数

在 `launch/complete_system.launch` 中可以调整：
- `follow_distance`: 跟随距离（默认1.0米）
- `max_linear_speed`: 最大线速度（默认1.2 m/s）
- `max_angular_speed`: 最大角速度（默认2.5 rad/s）

## 🔍 检查话题

如果第二辆车不跟随，可能是话题名称不对。运行：

```bash
source ~/catkin_ws/devel/setup.zsh
./scripts/check_robot_topics.sh
```

查看实际的话题名称，然后修改 `launch/complete_system.launch` 中的：
- `follower_odom_topic`: 第二辆车的odom话题
- `follower_cmd_topic`: 第二辆车的cmd_vel话题

## ⚠️ 可能的问题

### 问题1：第二辆车不移动

**检查话题**：
```bash
rostopic list | grep robot2
rostopic echo /robot2/odom  # 检查是否有数据
rostopic echo /robot2/cmd_vel  # 检查命令是否发布
```

**解决方案**：
1. 运行 `check_robot_topics.sh` 查看实际话题
2. 修改launch文件中的话题参数

### 问题2：话题冲突

如果两辆车使用相同的话题（如都使用 `/odom`），会导致冲突。

**解决方案**：
需要修改Gazebo插件配置，为第二辆车启用命名空间。这需要修改URDF文件或创建覆盖配置。

### 问题3：第二辆车位置不对

**调整位置**：
修改 `launch/complete_system.launch` 中spawn_robot2的x, y参数。

## 📊 工作原理

1. **第一辆车**：通过路径跟踪器按照Rviz中点击的路径行驶
2. **第二辆车**：通过跟随控制器，计算第一辆车后方1米的目标位置，然后控制第二辆车前往该位置

跟随算法：
- 计算第一辆车后方 `follow_distance` 米的目标点
- 根据距离和角度误差控制第二辆车
- 第二辆车的速度会根据第一辆车的速度动态调整

## 🎯 测试步骤

1. 启动系统
2. 在Rviz中点击路径点，让第一辆车开始移动
3. 观察第二辆车是否跟随第一辆车
4. 如果第二辆车不动，检查话题和日志

## 💡 提示

- 跟随距离可以在launch文件中调整
- 如果第二辆车跟不上，可以增加最大速度参数
- 查看 `follower_robot` 节点的日志了解跟随状态
