### 使用您的map.jpg（可选）

如果您想使用 `maps/map.jpg` 作为地图：

```bash
cd ~/catkin_ws/src/rl_line_following
source ~/catkin_ws/devel/setup.zsh
python3 scripts/convert_map_image.py
```

这会将 `map.jpg` 转换为 `maps/map.pgm` 和 `maps/map.yaml`。

然后在 `launch/complete_system.launch` 中修改地图路径：

```xml
<arg name="map_file" default="$(find rl_line_following)/maps/map.yaml"/>
```

## ✅ 验证地图是否加载

启动后，在Rviz中应该看到：
1. **地图背景** - 灰色/黑色网格的地图
2. **机器人模型** - 在地图上的小车
3. **网格线** - 帮助定位的网格

如果看不到地图：
1. 在Rviz左侧找到 "Map" 显示项
2. 确保它已启用（复选框勾选）
3. 检查 "Topic" 是否为 `/map`
4. 检查 "Fixed Frame" 是否为 `map`

## 🖱️ 使用2D Nav Goal添加路径点

### 步骤1：激活工具

1. 在Rviz工具栏上方找到 **"2D Nav Goal"** 工具
   - 图标是一个绿色箭头
   - 如果没有看到，可能在工具面板的下拉菜单中

2. **点击 "2D Nav Goal" 工具**使其激活（图标会高亮）

### 步骤2：点击地图添加路径点

1. 在Rviz的3D视图中，**点击地图上的任意位置**
2. 保持鼠标按下，**拖动鼠标**来设置目标点的朝向
3. **释放鼠标**，路径点已添加！

### 步骤3：验证路径点是否添加

**检查终端输出**：
- 应该看到类似这样的日志：
```
============================================================
收到2D Nav Goal消息！
  Frame: map
  位置: (2.500, 1.200)
  ...
✓ 成功添加路径点 #1: (2.50, 1.20)
当前路径共有 1 个点
============================================================
```

**检查Rviz显示**：
- 应该看到**红色小球**（路径点标记）
- 应该看到**绿色线条**（路径连线）
- 如果添加了多个点，它们会按顺序连接

### 步骤4：小车自动跟踪

- 一旦添加了至少1个路径点，小车会自动开始跟踪
- 小车会按照您点击的顺序依次访问每个路径点

## 🔍 故障排除

### 问题1：Rviz中没有地图

**检查map_server是否运行：**
```bash
source ~/catkin_ws/devel/setup.zsh
rostopic list | grep map
```

应该看到 `/map` 话题。

**检查地图话题：**
```bash
rostopic echo /map -n 1
```

应该能看到地图数据。

**解决方案：**
1. 检查launch文件中map_server节点是否启动
2. 检查地图文件路径是否正确
3. 在Rviz中添加Map显示类型，订阅 `/map` 话题

### 问题2：点击2D Nav Goal没有反应

**检查话题是否发布：**
```bash
source ~/catkin_ws/devel/setup.zsh
./test_2d_nav_goal.sh
```

或者在另一个终端运行：
```bash
source ~/catkin_ws/devel/setup.zsh
rostopic echo /move_base_simple/goal
```

然后点击2D Nav Goal，看是否有消息输出。

**检查节点是否订阅：**
查看 `rviz_path_planner` 节点的终端输出，应该看到：
```
已订阅话题: /move_base_simple/goal
```

**检查Rviz工具配置：**
1. 在Rviz左侧找到 "Tool Properties" 面板
2. 选择 "2D Nav Goal" 工具
3. 检查 "Topic" 是否设置为 `/move_base_simple/goal`

**常见问题：**
- 工具未激活 - 确保点击了工具栏上的2D Nav Goal图标
- Fixed Frame不正确 - 确保Rviz的Fixed Frame设置为 `map`
- 地图未加载 - 必须在地图加载后才能点击有效的位置

### 问题3：看不到路径点和连线

**解决方案：**
1. 在Rviz中添加以下显示类型：
   - **Marker** (订阅 `/planner/markers`) - 显示路径点
   - **Path** (订阅 `/planner/path`) - 显示路径连线

2. 确保这些显示项已启用（复选框勾选）

3. 检查Fixed Frame是否为 `map`

### 问题4：地图坐标不正确

如果地图位置不对，可能需要调整 `my_map.yaml` 中的 `origin` 参数：

```yaml
origin: [-10.0, -10.0, 0.0]  # 调整这些值来移动地图位置
```

### 问题5：小车不移动

**检查路径是否发布：**
```bash
source ~/catkin_ws/devel/setup.zsh
rostopic echo /planner/path
```

**检查控制命令：**
```bash
rostopic echo /cmd_vel
```

**检查odom话题：**
```bash
rostopic echo /odom
```

如果odom没有数据，小车无法知道自己在哪里，也就无法跟踪路径。
