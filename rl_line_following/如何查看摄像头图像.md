# 如何查看摄像头图像

根据您的检查结果，摄像头发布了以下话题：
- `/depth_camera/rgb/image_raw` - RGB彩色图像
- `/depth_camera/depth/image_raw` - 深度图像

## 方法1：使用OpenCV窗口查看（最简单）⭐

运行camera_viewer.py会自动显示摄像头图像：

```bash
# 在新的终端窗口中运行
python3 ~/catkin_ws/src/rl_line_following/scripts/camera_viewer.py
```

这会打开两个窗口：
- "RGB Camera View" - 显示彩色图像
- "Depth Camera View" - 显示深度图像（带颜色映射）

## 方法2：使用image_view查看器

```bash
# RGB图像
rosrun image_view image_view image:=/depth_camera/rgb/image_raw

# 深度图像
rosrun image_view image_view image:=/depth_camera/depth/image_raw
```

## 方法3：在Rviz中查看摄像头

### 步骤1：在Rviz中添加Image显示类型

1. 在Rviz中点击左上角的 **"Add"** 按钮
2. 点击 **"By topic"** 选项卡
3. 展开 **"depth_camera"** 分组
4. 找到 **"rgb/image_raw"** 或 **"depth/image_raw"**
5. 选择对应的 **"Image"** 显示类型
6. 点击 **"OK"**

### 步骤2：设置摄像头视图

1. 点击 **"Tool Properties"** 面板
2. 在 "Current Tool" 下拉菜单中选择 **"Camera"** 工具
3. 在3D窗口中点击并拖动，可以看到摄像头视角

### 或者添加Camera显示类型：

1. 点击 **"Add"** 按钮
2. 选择 **"Image"** 显示类型
3. 在 "Image Topic" 中填入：`/depth_camera/rgb/image_raw`
4. 点击 **"OK"**

## 验证话题是否发布

运行以下命令检查：

```bash
# 检查RGB图像
rostopic echo /depth_camera/rgb/image_raw --noarr -n 1

# 检查深度图像
rostopic echo /depth_camera/depth/image_raw --noarr -n 1

# 查看话题频率
rostopic hz /depth_camera/rgb/image_raw
```

## 故障排除

### 问题：看不到图像

1. **检查话题是否存在**：
   ```bash
   rostopic list | grep camera
   ```

2. **检查话题是否有数据**：
   ```bash
   rostopic hz /depth_camera/rgb/image_raw
   ```

3. **检查OpenCV是否正确安装**：
   ```bash
   python3 -c "import cv2; print(cv2.__version__)"
   ```

### 问题：Rviz中Camera显示类型提示"Image topic is not set"

这是因为话题名称没有正确配置。请在Rviz中添加Image显示时，手动输入话题名称：
- Image Topic: `/depth_camera/rgb/image_raw`

## 推荐工作流程

1. 启动Gazebo和机器人
2. 运行 `camera_viewer.py` 在单独的窗口中查看实时图像
3. 在Rviz中查看其他显示（路径、机器人等）

这样既能查看摄像头画面，又能看到完整的仿真环境。
