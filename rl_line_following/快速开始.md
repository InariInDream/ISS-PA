# 快速开始 - 交互式路径规划

## 🚀 三步快速启动

### 1. 编译工作空间（首次需要）

```bash
cd ~/catkin_ws
catkin_make
source devel/setup.zsh
```

### 2. 启动系统

```bash
cd ~/catkin_ws/src/rl_line_following
source ~/catkin_ws/devel/setup.zsh
roslaunch rl_line_following complete_system.launch
```

### 3. 在Rviz中绘制路径

1. 点击工具栏上的 **"2D Nav Goal"** 工具（绿色箭头图标）
2. 在地图上点击任意位置添加路径点
3. 重复步骤2添加更多点
4. 小车会自动开始跟踪路径！

## 📺 你会看到

- ✅ Gazebo仿真窗口
- ✅ Rviz可视化界面  
- ✅ OpenCV窗口（RGB + 深度摄像头）
- ✅ 终端中的路径点添加日志

## 🎯 添加路径点示例

在Rviz中点击顺序：
```
点1 (0, 0) → 点2 (2, 0) → 点3 (2, 2) → 点4 (0, 2) → 点1 (0, 0)
```

小车会按照这个顺序依次访问每个点！

## 🗑️ 清空路径

```bash
source ~/catkin_ws/devel/setup.zsh
./clear_path.sh
```

然后重新在Rviz中点击新路径。
