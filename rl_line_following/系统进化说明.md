# ROS路径跟踪系统 - 进化功能说明

## 🚀 新增功能概览

基于最新的ROS开源项目和论文研究，我们为系统添加了以下高级功能：

### 1. ✨ 动态障碍物避障
- **功能**：使用激光雷达实时检测前方障碍物
- **算法**：基于激光雷达数据的扇形区域检测
- **行为**：检测到障碍物时自动降低速度，避免碰撞
- **文件**：`scripts/path_tracker_with_obstacle_avoidance.py`

### 2. 📈 路径平滑优化
- **功能**：使用移动平均算法平滑路径点
- **效果**：减少路径的锯齿状，使小车行驶更平滑
- **文件**：`scripts/path_smoother.py`

### 3. ⚡ 速度规划（加速度限制）
- **功能**：添加加速度和减速度限制
- **效果**：避免突然加速/减速，运动更平滑自然
- **参数**：`max_acceleration`, `max_deceleration`

### 4. 📹 轨迹记录与回放
- **功能**：记录机器人行驶轨迹，支持保存和回放
- **用途**：分析路径、调试、重复执行相同路径
- **文件**：`scripts/trajectory_recorder.py`

### 5. 🎯 预测性跟随
- **功能**：第二辆车预测第一辆车的未来位置
- **算法**：基于速度和角速度的预测
- **效果**：跟随更平滑，减少延迟

### 6. 🎨 可视化增强
- **功能**：在Rviz中显示速度向量、速度文本等
- **文件**：`scripts/visualization_enhancer.py`

## 🎮 使用方法

### 启动增强版系统

```bash
source ~/catkin_ws/devel/setup.zsh
roslaunch rl_line_following enhanced_system.launch
```

这将启动：
- ✅ 标准功能（路径规划、跟踪、摄像头）
- ✅ 路径平滑器
- ✅ 增强版路径跟踪器（带障碍物避障）
- ✅ 轨迹记录器
- ✅ 双车跟随系统
- ✅ 可视化增强器

### 使用轨迹记录功能

**开始记录**：
```bash
rosservice call /trajectory/start_recording
```

**停止记录**：
```bash
rosservice call /trajectory/stop_recording
```

**保存轨迹**：
```bash
rosservice call /trajectory/save
```
轨迹会保存到 `trajectories/` 目录

**加载轨迹**：
```bash
rosservice call /trajectory/load
```
会加载最新的轨迹文件并在Rviz中显示

### 在Rviz中查看增强可视化

添加以下显示类型：
1. **MarkerArray** (订阅 `/visualization/markers`) - 显示速度向量和文本
2. **Path** (订阅 `/robot/recorded_trajectory`) - 显示记录的轨迹
3. **Path** (订阅 `/robot/trajectory`) - 显示实时轨迹历史

## ⚙️ 配置参数

### 障碍物避障参数

在 `enhanced_system.launch` 中：
```xml
<param name="obstacle_threshold" value="0.5"/>  <!-- 障碍物检测距离（米） -->
<param name="avoidance_angle" value="30.0"/>    <!-- 检测角度范围（度） -->
<param name="avoidance_speed_reduction" value="0.5"/>  <!-- 速度降低比例 -->
```

### 速度规划参数

```xml
<param name="max_acceleration" value="0.5"/>    <!-- 最大加速度 m/s² -->
<param name="max_deceleration" value="0.8"/>    <!-- 最大减速度 m/s² -->
```

### 路径平滑参数

```xml
<param name="smoothing_factor" value="0.3"/>    <!-- 平滑因子（0-1） -->
```

## 🔬 技术细节

### 障碍物避障算法

1. 订阅激光雷达数据 (`/scan`)
2. 检查前方±30度扇形区域
3. 如果最小距离 < 阈值（0.5米），降低速度
4. 速度降低比例可配置

### 路径平滑算法

1. 使用移动平均滤波器
2. 窗口大小：3个点
3. 平滑因子：0.3（30%平滑，70%保持原样）

### 速度规划算法

1. 计算目标速度
2. 根据加速度限制计算速度变化
3. 逐步调整到目标速度
4. 避免突然的速度变化

### 预测性跟随算法

1. 获取第一辆车的速度和角速度
2. 预测未来0.5秒的位置
3. 在预测位置后方设置目标点
4. 第二辆车前往预测目标点

## 📊 性能优化建议

1. **障碍物检测**：如果激光雷达频率低，可以降低检测频率
2. **路径平滑**：如果路径点很多，可以增加平滑窗口
3. **速度规划**：根据机器人物理特性调整加速度限制

## 🐛 故障排除

### 问题1：路径平滑器报错（scipy未安装）

**解决方案**：
```bash
pip3 install scipy
# 或
sudo apt-get install python3-scipy
```

### 问题2：障碍物避障不工作

**检查**：
```bash
rostopic echo /scan  # 检查激光雷达数据
```

**解决方案**：
- 确保激光雷达话题正确
- 检查障碍物阈值是否合适

### 问题3：轨迹记录失败

**检查**：
```bash
ls ~/catkin_ws/src/rl_line_following/trajectories/
```

**解决方案**：
- 确保目录有写权限
- 检查磁盘空间
